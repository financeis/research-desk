# 0022 — 유사 기업 카드 모델은 `claude-sonnet-5-5`(시험 실행 뒤 사용자 결정)

## 배경
유사 기업 찾기는 회사마다 사업보고서로 만든 AI 사업 요약 카드(프로필)를 임베딩해 비교한다. 카드 품질이 임베딩·용어표·테마 검색까지 유사도 전체를 정하고, 추출은 1년에 한 번 상장사 전체(약 2,500곳)에 돈다. 2026-10-10 FY2024 임시 자료로 `claude-haiku-5-5` 시험 실행(`peers build --pilot`, 34곳)을 했다: 34곳 모두 성공, 정보 부족 3곳, 근거율 0.8 미만으로 `gpt-5.4` 재추출 6곳(18%), 회사당 입력 약 9.6K·출력 약 1.7K 토큰, 930곳 어림 비용 약 5~11달러.

## 결정
- 프로필 추출 모델의 기본값은 `claude-sonnet-5-5`(`LLM_MODEL_PEERS`)다. 재추출 모델은 `gpt-5.4`(`LLM_MODEL_PEERS_ESCALATION`), 임베딩은 `text-embedding-3-large` 1536차원 그대로다.
- 비교 실행 없이 사용자가 정했다. 카드 품질이 결과 전체를 정하고 실행이 연 1회라 비용보다 품질을 택했다.
- 실제 933곳 빌드(2026-10-10): 모두 성공(Sonnet 822곳, `gpt-5.4` 재추출 111곳), 정보 부족 17곳, 입력 약 868만·출력 약 63만 토큰, 비용 약 25~35달러, 사용자 승인으로 그 실행만 동시 8로 약 18분.

## 버린 대안
- **`claude-haiku-5-5`**: 비용은 5분의 1 수준이지만 재추출 비율이 18%였고, 카드가 흐리면 그 위의 모든 계산이 흐려진다. 연 1회 비용 차이가 수십 달러라 감수하지 않았다.
- **GPT 계열(`gpt-5.4` 등)**: 비교 측정을 하지 않았다. 비교하려면 모델마다 프로필 버전을 시험용 값으로 달리 두고 같은 회사로 시험 실행해야 한다(같은 버전이면 저장된 프로필을 재사용해 새 모델이 불리지 않는다).
- **Codex CLI 경로(`codex:` 모델)**: 수백~수천 건 배치는 ChatGPT 로그인 한도에 맞지 않는다(태깅에 쓰지 않는 이유와 같다).

## 결과
- 유사 기업 기능은 `ANTHROPIC_API_KEY`(추출)와 `OPENAI_API_KEY`(재추출·임베딩)가 둘 다 있어야 돈다.
- 모델을 바꿔도 같은 (회계연도, 프로필 버전)의 `ok` 프로필은 재사용되므로, 새 모델로 다시 만들려면 프로필 버전(`PEERS_PROFILE_VERSION`)을 올려야 하고 그때 전체 재추출 비용이 든다.
- 모델 비교 측정은 시험용 프로필 버전 값으로 한다. 고른 뒤에는 시험용 값을 지우고 본 실행을 한다.
