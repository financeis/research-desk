# 0027 — 글자 없는 PDF는 분석도 쪽 그림으로 읽는다

## 배경
리포트 1건 재무 분석은 PDF 글자를 쪽 표시(`--- Page N ---`)와 함께 AI에게 보낸다. 본문 글자가 뽑히지 않는 PDF도 쪽 표시는 들어가므로 "글자가 있다"로 보고 AI를 불렀고, AI는 "본문이 안 보여 확인할 수 없음"이라는 빈 결과를 돌려줬다. 빈 결과도 재무 상세가 있으면 재사용되고 화면의 분석 버튼이 숨겨져, 고칠 길이 없었다.

2026-10-11에 운영 데이터를 읽어 본 결과는 다음과 같다.
- 저장된 분석 46건 중 3건이 이런 빈 결과였다. AI가 지어낸 숫자는 없었다.
- 셋 다 완전한 스캔본이 아니었다. 글자 층에 차트 눈금, `Fig. 1:`, FnGuide 저작권 문구만 있고 본문 한글은 하나도 뽑히지 않았다. 그래서 "글자가 0이면"이라는 기준으로는 잡히지 않는다.
- 분석 대상 단일종목 300건 표본에서 17건(약 6%)이 이런 PDF였고, 대부분 미래에셋증권이었다.
  - 본문이 빠진 PDF: 쪽당 한글 평균 0~38자, 영문 약 50자 이하(대부분 저작권 문구)
  - 글이 짧아도 정상인 PDF: 76자 이상
  - 보통 리포트: 200자 이상
- 표본에 영어로 쓴 리포트는 없었다.

## 결정
- **판정.** PDF 모든 쪽의 글자로 문서 전체를 한 번 판정한다. 쪽당 한글 평균이 50자 미만이고 영문 글자 평균이 300자 미만이면 그림 분석이다. 딱 같으면 글자 분석이다. 기준값은 코드 상수다(사용자 선택).
- **그림 분석.**
  - 1쪽부터 최대 20쪽을 120dpi 그림으로 그려(크기 한도를 넘으면 낮춤) 같은 시스템 프롬프트로 AI에게 보여 준다(사용자 선택).
  - 숫자는 원문 대조 없이 저장하고, 화면에 `그림으로 읽음 · 숫자 원문 대조 안 됨`을 표시한다(사용자 선택).
  - 추출 신뢰도는 최대 `medium`이다.
- **시간 한도.** 그림 분석은 호출 한 번 `PHASE2_IMAGE_TIMEOUT_S`(360초)이고, 시간 초과는 자동으로 다시 시도하지 않는다(사용자 선택).
- **빈 결과.** 그림으로 읽고도 목표주가 없음·투자의견 `N/A`·재무 지표 0개·신뢰도 `low`를 모두 만족하면 저장하지 않고 422로 알린다(사용자 선택).
- **그림을 쓸 수 없을 때.** 분석 모델이 그림을 받지 못하거나 한 쪽도 그리지 못하면, 빈 글로 AI를 부르지 않고 422로 거절한다.
- **읽은 방식 저장.** 분석 결과 표에 새 칸 `input_mode`(`text`|`page_image`)를 마이그레이션 010으로 더한다(사용자 선택).

## 버린 대안
- **처음 기준 한글 30자**: 사용자가 먼저 골랐다. 그런데 표본에서 제목만 뽑히고 본문이 빠진 리포트가 37~38자였고, 30으로는 이를 놓친다. 정상인 짧은 리포트가 76자라 50으로 올렸다(사용자 확인).
- **한글만 보는 기준**: 영어로 쓴 리포트가 들어오면 그림으로 가서 숫자 대조를 잃고 더 느려진다. 영문 조건을 더했다.
- **쪽마다 따로 판정**(글자 있는 쪽은 글자, 없는 쪽만 그림): 보통 리포트의 차트 쪽까지 그림이 되어 대부분의 분석이 느려지고 사용 한도를 더 쓴다.
- **AI에게 그림을 글로 옮겨 적게 한 뒤 그 글로 대조**: 시간·사용량이 두 배다. 또 AI 자기 글과 대조하는 셈이라 효과가 약하다.
- **그림 분석의 재무 지표 버리기**: 요약·의견만 남아 쓸모가 적다.
- **최대 10쪽 / 제한 없음**: 10쪽은 뒤쪽 재무제표 요약을 놓친다. 제한이 없으면 긴 리포트가 시간 한도에 걸린다. 표본의 97%가 20쪽 이하다.
- **시간 초과도 한 번 더 시도(글자 분석과 같게)**: Codex 사용 한도를 두 배로 쓰고 AI 자리를 오래 잡는다.
- **표시를 재무 상세 JSON 안에 넣기**: 마이그레이션이 필요 없다. 하지만 재무 상세가 없는 그림 결과에서는 표시가 사라진다.
- **분류기의 그림 그리기 코드를 공용으로 옮기기**: 분류기 운영 적용이 중간에 멈춰 있어 손대지 않았다. `core.pdf.render_pages_fitting`을 새로 두고, 한 장 한도 값만 같게 맞췄다. 분류기가 이 함수로 옮겨 가는 일은 발견 문서에 남긴다.

## 결정 0018과의 관계
0018(분류)은 비용 때문에 "늘 그림을 보여 주기"를 버리고, 글자가 하나도 없을 때만 1쪽 그림을 보냈다. 이 결정도 같은 원칙이다: 글자가 사실상 없을 때만 그림을 보낸다. 다른 점은 두 가지다. 분석은 본문 전체가 필요해 최대 20쪽을 보낸다. 그리고 "글자가 0"이 아니라 "본문 글자가 사실상 없음"을 기준으로 한다(저작권 문구·차트 눈금만 뽑히는 배포본 때문). 신뢰도 상한 `medium`은 0018과 같은 대접이다.

## 결과
- 미래에셋증권 리포트처럼 글자가 뽑히지 않는 PDF도 재무 정보가 나온다. 이런 리포트에서는 그림 분석이 주된 경로다.
- 그림 분석은 글자 분석보다 오래 걸리고 사용 한도를 더 쓴다. 숫자는 원문과 자동 대조되지 않으므로, 화면 표시와 근거 쪽 링크로 사람이 확인한다.
- 앞 최대 20쪽의 그림(애널리스트 연락처 등 쪽에 보이는 모든 것)이 분석 모델 공급자로 간다.
- 분석 모델은 그림을 받는 모델이어야 글자 없는 PDF를 분석할 수 있다.
